Privacy Policy

Last updated: 2026-10-17

← email-tools

email-tools is a personal tool used only by its developer to read their own email. This policy explains what data it touches.

Data accessed

With the owner's explicit consent, email-tools accesses the owner's Gmail messages and metadata (sender, subject, date, body text) using the read-only scope https://www.googleapis.com/auth/gmail.readonly.

How data is used

Email content is read only to list and summarize the owner's own messages. It is not used for advertising, profiling or any purpose unrelated to that.

Storage and sharing

  • Email content is not sold, shared or disclosed to any third party.
  • Email content is not stored on any third-party servers operated for this tool.
  • OAuth credentials (client ID, secret and refresh token) are kept in a private configuration file on the owner's own machine and are never published.

Google API Services User Data Policy

email-tools's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
